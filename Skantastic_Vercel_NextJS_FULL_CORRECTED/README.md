Skantastic.com – Vercel Website (Premium + SEO)

What you get:
- Premium single-page landing site aligned with the App Store tone
- Built-in SEO (title/description, OpenGraph/Twitter, canonical)
- Schema.org MobileApplication JSON-LD
- robots + sitemap routes
- Screenshots already included

How to use:
1) Unzip this package
2) In the folder, run:
   npm install
   npm run dev
3) Deploy to Vercel:
   - Option A: Upload to a GitHub repo and import it in Vercel
   - Option B: Replace the files in your existing Vercel project repo and redeploy

IMPORTANT:
- Replace the App Store URL placeholder:
  Search for idYOURAPPID in:
    /app/layout.tsx
    /app/page.tsx
  and paste your real App Store link once approved.
