Skantastic Next.js Website (Vercel) – FULL CORRECTED VERSION

This version is built for Vercel’s default Next.js deployment (no 404 routing issues).

Deploy steps:
1) Upload these files to the ROOT of your GitHub repo (not inside a subfolder).
2) In Vercel, create a NEW project (recommended) and import that repo.
3) Framework preset should auto-detect Next.js.
4) Deploy.

After you have your App Store link, replace idYOURAPPID in:
- /app/layout.tsx
- /app/page.tsx

Optional: Put your final og-image in /public/images/og-image.jpg (already included).
